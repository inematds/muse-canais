En resumen

muse-canais es un script en Python que analiza tus canales de YouTube y muestra qué videos recientes están rindiendo muy por encima de lo habitual en cada canal. Es útil para quienes publican mucho y quieren repetir lo que funciona en lugar de adivinar. Lee el feed público de cada canal (los 15 videos más recientes, con sus visualizaciones), sin iniciar sesión ni usar una clave, y compara la velocidad de cada video con la del video típico de ese canal. Los que superan 2 veces el valor habitual se convierten en «ganadores» y, si lo pides, en 8 nuevas ideas de video. Solo necesitas Python 3; las ideas usan Claude Code con tu suscripción.

Qué es

Un informe de qué repetir, canal por canal

Cada canal se compara consigo mismo. Un canal pequeño no desaparece junto a uno grande.

🔓 Solo datos públicos

Lee el feed RSS que el propio YouTube ofrece para cada canal (un archivo con los videos más recientes). No pide contraseña, no usa la API de YouTube ni necesita ninguna clave.

📊 Comparación justa

Mide las visualizaciones por hora de cada video y las divide por la mediana del canal (el valor del medio, que no se deja arrastrar por un video fuera de lo común). Si supera 2×, es ganador.

💡 Ideas que tú eliges

Con --ideias, Claude Code lee los títulos y las cifras de los ganadores y propone 8 nuevos videos siguiendo el mismo patrón, con título, gancho y formato. No se produce nada automáticamente: tú eliges.

Cómo funciona

Del feed al informe

Todo con un solo comando. Solo la etapa de las ideas usa Claude Code; el resto lo calcula el propio script.

Lista de canales (canais.json)→ Feed público de cada canal→ Visualizaciones por hora→ Valor habitual del canal→ Ganadores→ 8 ideas (opcional)→ Tu elección

Velocidad

Visualizaciones ÷ horas desde la publicación. Un video con 900 visualizaciones en 100 horas avanza a 9 por hora.

Valor habitual del canal

La mediana de velocidad de los videos del canal con más de 6 horas, con un piso de 0,5 por hora: así, un canal casi inactivo no hace que cualquier video parezca un éxito.

Ganador

2× el valor habitual o más (ajustable con --limiar), con entre 6 horas y 30 días de antigüedad y al menos 50 visualizaciones. El informe muestra hasta 15.

Requisitos previos

Qué necesitas

No necesitas una clave de pago. Funciona en Linux, Mac o Windows con WSL (el Linux que se ejecuta dentro de Windows).

Python 3 y git

El script usa solo lo que ya viene con Python; no tienes que instalar nada con pip. git descarga el proyecto. Comprueba que ambos estén en tu equipo:

python3 --version && git --version

Claude Code (solo para las ideas)

La opción --ideias llama a Claude Code con tu suscripción (se instala desde claude.com/claude-code). Debes haber iniciado sesión: ejecuta claude una vez e inicia sesión en tu cuenta antes de usar --ideias. Sin Claude Code, el informe de ganadores funciona igual; simplemente no se generan ideas.

claude --version

La dirección de tus canales

El enlace de cada canal, como https://www.youtube.com/@seucanal. Puede ser el tuyo o el de canales de otras personas que sigues: el feed es público.

Guía de uso · paso a paso

Desde cero hasta el primer informe

Comandos que puedes copiar, en orden. Pega un bloque a la vez en la terminal.

1

Descarga el proyecto

Copia el proyecto en la carpeta ~/projetos/muse-canais y entra en ella.

git clone https://github.com/inematds/muse-canais ~/projetos/muse-canais
cd ~/projetos/muse-canais
2

Encuentra el ID de cada canal

El feed de YouTube necesita el ID del canal (un código que empieza con UC), no el @. El propio script tiene una función que encuentra ese código a partir de la dirección. Ejecútala dentro de la carpeta del proyecto (después del cd del paso 1). Cambia @seucanal por el tuyo y repite el proceso para cada canal.

python3 -c "import muse; print(muse.resolver_id('https://www.youtube.com/@seucanal'))"

Verás algo como UC2QbQDyPKuHk93dwo5iq3Sw. Si aparece None, comprueba la dirección.

3

Escribe tu lista de canales

El archivo canais.json que viene con el proyecto contiene los canales de INEMA. Abre el archivo en el editor de la terminal con nano canais.json (o en VS Code) y reemplaza todo el contenido por tus canales, un bloque por canal, separados por comas. No borres el archivo: escribe encima. La primera palabra de cada bloque (meucanal, segundo) es un apodo corto que tú eliges; sirve para la opción --canais.

{
  "meucanal": {"nome": "Mi canal", "url": "https://www.youtube.com/@meucanal", "id": "UC…"},
  "segundo": {"nome": "Mi segundo canal", "url": "https://www.youtube.com/@segundo", "id": "UC…"}
}

En lugar de UC…, pega el ID del paso 2. Los canales sin ID se omiten. Ten cuidado con las comillas y las comas: si falta una, o sobra una coma después del último canal, el script se detiene con un error. En nano, guarda con Ctrl+O y Enter y sal con Ctrl+X. La opción --atualiza-canais del README solo sirve si también usas yt-pubx (la herramienta de publicación de INEMA); si escribiste la lista a mano, no la necesitas.

4

Revisa los resultados sin guardar nada

Con --dry, lee los feeds y solo muestra los ganadores en pantalla, sin crear archivos ni historial.

python3 muse.py --dry

La última línea indica cuántos videos leyó, cuántos ganadores encontró y qué canales quedaron «sin respuesta» (cuando YouTube rechaza el feed en ese momento). Si aparece algún canal sin respuesta, vuelve a ejecutarlo más tarde.

5

Genera el informe con ideas

Sin --dry, guarda el informe. Con --ideias, Claude Code propone 8 nuevos videos a partir de los ganadores (puede tardar unos minutos). Si ningún video superó 2×, ese día no habrá ideas. Si la lista tiene ganadores y aun así no salieron ideas, el problema es Claude Code (no instalado o sin iniciar sesión): pruébalo con claude -p "hola".

python3 muse.py --ideias

El informe queda en ~/projetos/output/muse-canais/<data>/muse.md (para leer) y muse.json (los mismos datos en JSON, un formato de texto que pueden leer otros programas). Para guardarlo en otra carpeta, define MUSE_SAIDA antes del comando, por ejemplo: MUSE_SAIDA=~/relatorios python3 muse.py --ideias.

Atención: la instrucción para generar ideas está escrita para INEMA (canales que enseñan IA). Para otro tema, abre muse.py, busca la línea que empieza con Você é o pauteiro do INEMA —está en portugués porque es el texto literal del archivo— y reemplázala por una descripción de tus canales. En la línea siguiente, cambia también NOSSOS canais si quieres, y más adelante, el ejemplo ex.: lives11 por un apodo de tu canais.json. Cada idea incluye un formato: short 9:16 (video vertical corto), 16:9 (video horizontal común) o carrossel (publicación con varias imágenes).

6

Personaliza las opciones cuando quieras

Las opciones se pueden combinar. Los nombres después de --canais son los apodos de tu canais.json.

12 ideas en vez de 8:

python3 muse.py --ideias --n 12

Solo videos con 3× el valor habitual o más:

python3 muse.py --limiar 3

Solo estos canales:

python3 muse.py --canais meucanal,segundo

A partir de la segunda ejecución (sin --dry), el script también guarda las visualizaciones de cada video en estado/historico.jsonl y anota en muse.json cuántas visualizaciones ganó cada video entre una ejecución y otra. Los ganadores se siguen determinando por la velocidad desde la publicación.

7

Ejecuta todo a diario automáticamente (opcional)

El proyecto incluye una tarea programada de Linux (systemd) que ejecuta muse.py --ideias todos los días a las 08:00. Viene desactivada. Funciona en Linux y en WSL con systemd habilitado; Mac no tiene systemd, así que debes ejecutar el comando manualmente. El servicio espera encontrar el proyecto en ~/projetos/muse-canais. Para activarlo, desde la carpeta del proyecto:

mkdir -p ~/.config/systemd/user
cp systemd/muse-canais.* ~/.config/systemd/user/
systemctl --user daemon-reload
systemctl --user enable --now muse-canais.timer

Si también usas radar-pautas (otro proyecto de INEMA que reúne las noticias del día y sugiere temas), las tendencias del día se incluyen automáticamente en la solicitud de ideas.

Límites y próximos pasos

Qué no hace

Para que sepas qué esperar del informe.

Límite
Solo los 15 videos más recientesEl feed público no incluye videos más antiguos, tiempo de reproducción ni retención.
Límite
Cifras con algunas horas de retrasoLas visualizaciones del feed llegan más tarde que las de YouTube Studio y, a veces, YouTube rechaza el feed de un canal: aparece como «sin respuesta».
Límite
Las ideas solo ven títulos y cifrasNo ven los videos. Todo dato o cifra de un video nuevo necesita una fuente propia; la instrucción pide marcarlo como «dato por confirmar».
