Em resumo

O muse-canais é um script em Python que olha os seus canais do YouTube e mostra quais vídeos recentes estão indo bem acima do normal de cada canal. Serve para quem publica muito e quer repetir o que funciona em vez de adivinhar. Ele lê o feed público de cada canal (os 15 vídeos mais recentes, com as visualizações), sem login e sem chave, e compara a velocidade de cada vídeo com a do vídeo típico do mesmo canal. Os que passam de 2 vezes viram "vencedores" e, se você pedir, viram 8 ideias novas de vídeo. Precisa só de Python 3; as ideias usam o Claude Code pela sua assinatura.

O que é

Um relatório do que repetir, canal por canal

Cada canal é comparado com ele mesmo. Um canal pequeno não some ao lado de um grande.

🔓 Só dados públicos

Lê o feed RSS que o próprio YouTube oferece para cada canal (um arquivo com os vídeos mais recentes). Não pede senha, não usa a API do YouTube e não precisa de chave de nada.

📊 Comparação justa

Mede as visualizações por hora de cada vídeo e divide pela mediana do canal (o valor do meio, que não se deixa puxar por um vídeo fora da curva). Quem passa de 2× é vencedor.

💡 Ideias que você escolhe

Com --ideias, o Claude Code lê os títulos e os números dos vencedores e propõe 8 vídeos novos no mesmo padrão, com título, gancho e formato. Nada é produzido sozinho: você escolhe.

Como funciona

Do feed ao relatório

Tudo em um comando. Só a etapa das ideias usa o Claude Code; o resto é conta feita pelo próprio script.

Lista de canais (canais.json)→ Feed público de cada canal→ Visualizações por hora→ Normal do canal→ Vencedores→ 8 ideias (opcional)→ Sua escolha

Velocidade

Visualizações ÷ horas desde a publicação. Um vídeo com 900 visualizações em 100 horas anda a 9 por hora.

Normal do canal

A mediana da velocidade dos vídeos do canal com mais de 6 horas, com piso de 0,5 por hora: assim um canal quase parado não faz qualquer vídeo parecer um sucesso.

Vencedor

2× o normal ou mais (ajustável com --limiar), entre 6 horas e 30 dias de idade e com pelo menos 50 visualizações. O relatório mostra até 15.

Pré-requisitos

O que precisa ter

Nada de chave paga. Roda no Linux, no Mac ou no Windows pelo WSL (o Linux que roda dentro do Windows).

Python 3 e git

O script usa só o que já vem com o Python; não há nada para instalar com pip. O git baixa o projeto. Confira se os dois estão na máquina:

python3 --version && git --version

Claude Code (só para as ideias)

A opção --ideias chama o Claude Code pela sua assinatura (instalação em claude.com/claude-code). Ele precisa estar logado: rode claude uma vez e entre na sua conta antes de usar --ideias. Sem ele, o relatório de vencedores funciona igual; só não saem as ideias.

claude --version

O endereço dos seus canais

O link de cada canal, como https://www.youtube.com/@seucanal. Pode ser o seu e também canais de outras pessoas que você acompanha: o feed é público.

Guia de uso · passo a passo

Do zero ao primeiro relatório

Comandos copiáveis, na ordem. Cole um bloco por vez no terminal.

1

Baixe o projeto

Copia o projeto para a pasta ~/projetos/muse-canais e entra nela.

git clone https://github.com/inematds/muse-canais ~/projetos/muse-canais
cd ~/projetos/muse-canais
2

Descubra o ID de cada canal

O feed do YouTube pede o ID do canal (um código que começa com UC), não o @. O próprio script tem uma função que acha esse código a partir do endereço. Rode dentro da pasta do projeto (depois do cd do passo 1). Troque @seucanal pelo seu e repita para cada canal.

python3 -c "import muse; print(muse.resolver_id('https://www.youtube.com/@seucanal'))"

Sai algo como UC2QbQDyPKuHk93dwo5iq3Sw. Se sair None, confira o endereço.

3

Escreva a sua lista de canais

O canais.json que vem no projeto tem os canais do INEMA. Abra o arquivo no editor do terminal com nano canais.json (ou no VS Code) e troque todo o conteúdo pelos seus canais, um bloco por canal, separados por vírgula. Não apague o arquivo: escreva por cima dele. A primeira palavra de cada bloco (meucanal, segundo) é um apelido curto que você escolhe; ele serve para a opção --canais.

{
  "meucanal": {"nome": "Meu canal", "url": "https://www.youtube.com/@meucanal", "id": "UC…"},
  "segundo": {"nome": "Meu segundo canal", "url": "https://www.youtube.com/@segundo", "id": "UC…"}
}

No lugar de UC…, cole o ID do passo 2. Canal sem ID é pulado. Cuidado com as aspas e as vírgulas: uma faltando, ou uma vírgula sobrando depois do último canal, e o script para com erro. No nano, salve com Ctrl+O e Enter e saia com Ctrl+X. A opção --atualiza-canais do README só serve para quem também usa o yt-pubx (a ferramenta de publicação do INEMA); com a lista escrita à mão, você não precisa dela.

4

Dê uma olhada sem gravar nada

Com --dry, ele lê os feeds e só mostra na tela os vencedores, sem criar arquivo nem histórico.

python3 muse.py --dry

A última linha diz quantos vídeos leu, quantos vencedores achou e quais canais ficaram "sem resposta" (quando o YouTube recusa o feed naquela hora). Se aparecer canal sem resposta, rode de novo mais tarde.

5

Gere o relatório com as ideias

Sem --dry, ele grava o relatório. Com --ideias, o Claude Code propõe 8 vídeos novos a partir dos vencedores (pode levar alguns minutos). Se nenhum vídeo passou de 2×, não há ideias nesse dia. Se a lista tem vencedores e mesmo assim não saíram ideias, o problema é o Claude Code (não instalado ou sem login): teste com claude -p "oi".

python3 muse.py --ideias

O relatório fica em ~/projetos/output/muse-canais/<data>/muse.md (para ler) e muse.json (os mesmos dados em JSON, o formato de texto que outros programas leem). Para gravar em outra pasta, defina MUSE_SAIDA antes do comando, ex.: MUSE_SAIDA=~/relatorios python3 muse.py --ideias.

Atenção: o pedido das ideias está escrito para o INEMA (canais que ensinam IA). Para outro assunto, abra o muse.py, procure a linha que começa com Você é o pauteiro do INEMA e troque pela descrição dos seus canais. Na linha logo abaixo, troque também NOSSOS canais se quiser, e, mais abaixo, o exemplo ex.: lives11 por um apelido do seu canais.json. Cada ideia sai com um formato: short 9:16 (vídeo curto em pé), 16:9 (vídeo deitado comum) ou carrossel (post de várias imagens).

6

Ajuste quando quiser

As opções se combinam. Os nomes depois de --canais são os apelidos do seu canais.json.

12 ideias em vez de 8:

python3 muse.py --ideias --n 12

Só vídeos com 3× o normal ou mais:

python3 muse.py --limiar 3

Só esses canais:

python3 muse.py --canais meucanal,segundo

A partir da segunda rodada (sem --dry), o script também guarda as visualizações de cada vídeo em estado/historico.jsonl e anota, no muse.json, quanto cada vídeo ganhou entre uma rodada e outra. Quem é vencedor continua sendo decidido pela velocidade desde a publicação.

7

Todo dia sozinho (opcional)

O projeto traz um agendamento do Linux (systemd) que roda muse.py --ideias todo dia às 08:00. Ele vem desligado. Funciona no Linux e no WSL com systemd ligado; no Mac não existe systemd, então rode o comando à mão. O serviço espera o projeto em ~/projetos/muse-canais. Para ligar, de dentro da pasta do projeto:

mkdir -p ~/.config/systemd/user
cp systemd/muse-canais.* ~/.config/systemd/user/
systemctl --user daemon-reload
systemctl --user enable --now muse-canais.timer

Se você também usa o radar-pautas (outro projeto do INEMA, que junta as notícias do dia e sugere pautas), as pautas em alta do dia entram junto no pedido das ideias, sem fazer nada a mais.

Limites e próximos passos

O que ele não faz

Para você saber o que esperar do relatório.

Limite
Só os 15 vídeos mais recentesO feed público não traz vídeos mais antigos, tempo assistido nem retenção.
Limite
Números com algumas horas de atrasoAs visualizações do feed chegam atrasadas em relação ao YouTube Studio, e às vezes o YouTube recusa o feed de um canal: ele aparece em "sem resposta".
Limite
As ideias veem só título e númerosElas não assistem aos vídeos. Todo fato ou número de um vídeo novo precisa de fonte própria; o pedido manda marcar "dado a confirmar".
